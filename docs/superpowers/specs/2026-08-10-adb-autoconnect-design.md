# 雷电 ADB 自动连接修复设计

## 根因

雷电 14 实例 0 启动后在 `127.0.0.1:5555` 监听，但不会自动注册到 `adb devices`。现有程序只轮询设备列表，因此持续得到空列表并在 120 秒后超时。执行 `adb connect 127.0.0.1:5555` 后设备立即可用。

## 修复

`LDPlayerManager.adb_devices()` 首次读取不到任何雷电设备时，主动执行一次 `adb connect`。目标地址只根据配置的雷电实例索引计算：实例 0 使用 `127.0.0.1:5555`，之后每个实例端口增加 2。连接后重新读取 `adb devices` 并返回真实状态；连接尚未成功时保留空结果，由现有启动轮询继续重试。

显式配置 `adb.address` 时不使用端口推导，继续尊重用户配置。

## 验证

单元测试模拟第一次设备列表为空、连接成功、第二次出现设备，验证命令顺序和返回值。另一个测试验证显式地址不触发自动端口连接。完整测试、Ruff 和真实签到运行均需通过。
