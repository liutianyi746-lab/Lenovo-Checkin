# 首次配置入口设计

## 目标

让不同雷电安装路径的 Windows 用户无需手工编辑 YAML，即可为联想签到器生成本机专用配置，同时保留现有自动发现能力。

## 用户流程

仓库根目录新增 `首次配置.bat`。用户通常无需运行它：公开的 `config.yaml` 默认使用 `auto`，程序会依次检查雷电常见安装目录、正在运行的雷电进程和 Windows 注册表。

只有自动识别失败时，用户才双击 `首次配置.bat`：

1. 脚本提示用户把 `dnplayer.exe` 拖入窗口，或粘贴其完整路径。
2. 脚本移除拖入路径两侧可能存在的引号，并验证文件存在且文件名为 `dnplayer.exe` 或 `LDPlayer.exe`。
3. 脚本优先检查播放器同目录下的 `adb.exe`。
4. 如果同目录没有 `adb.exe`，提示用户拖入或粘贴 `adb.exe` 的完整路径并验证。
5. 脚本在项目根目录生成完整的 `config.local.yaml`，保留实例索引 `0`、运行后关闭模拟器和现有超时配置。
6. 成功后显示生成位置，并提示运行 `python main.py` 测试。

## 文件与配置边界

- `config.yaml`：公开、通用，使用 `ldplayer.executable_path: auto` 和 `adb.executable_path: adb`。
- `config.local.yaml`：每台电脑私有，程序优先读取，已加入 `.gitignore`。
- `首次配置.bat`：只生成或覆盖项目目录中的 `config.local.yaml`，不修改公开配置。

脚本覆盖已有 `config.local.yaml` 前必须询问用户确认。用户拒绝时不改变文件并以非零退出码结束。

## 测试

通过 Python 测试在临时目录运行批处理脚本，并使用带空格和中文的临时雷电目录：

1. 输入有效 `dnplayer.exe` 且同目录存在 `adb.exe` 时，退出码为 `0`，生成的 YAML 可由项目的 `load_config()` 读取，两条可执行路径与输入一致。
2. 输入不存在的播放器路径时，退出码非零且不生成配置。
3. 已有本机配置且用户拒绝覆盖时，退出码非零，原文件内容保持不变。

## README 调整

安装指南先说明自动识别，无需照抄作者路径。排错章节提供 `首次配置.bat` 的使用步骤，并保留手工创建 `config.local.yaml` 的高级用法。

## 安全与兼容性

- 所有文件路径均加双引号，支持空格和中文目录。
- 配置中使用 YAML 单引号表示 Windows 路径，避免反斜杠转义问题。
- 脚本不扫描整个磁盘，不下载程序，也不以管理员权限运行。
- 脚本不读取或保存联想账号、密码、Cookie、日志、截图或 Android 数据。
